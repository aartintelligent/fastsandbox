Docker Sandboxes for Python

Coding agents,
in throw-away sandboxes.

A typed async client and a declarative framework over Docker Sandboxes (sbx). Declare an agent task: every run gets its own microVM, its own network rules and its own credentials, and is deleted when it ends.

Requires Docker Sandboxes on the machine: fastsandbox connects to the socket of its daemon.
