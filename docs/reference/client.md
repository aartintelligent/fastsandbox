# Client

The entry point of the client: [`connect()`][fastsandbox.connect] opens a
[`Client`][fastsandbox.Client] on the socket of the daemon, and
[`Client.create()`][fastsandbox.Client.create] returns a
[`Creation`][fastsandbox.Creation], awaited or used as an async context
manager.
